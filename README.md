# Clip Vault by Fahim

Hybrid (AI + manual) video clipping website.

- Upload a long video by file or drag & drop
- AI best-moments scan with viral score, silence detection/skip
- Timeline: trim, split, speed, zoom, auto-reframe, filters, transitions
- Auto captions (Whisper, in-browser) burned into the export
- Export 1080p MP4, all sizes: 9:16 / 16:9 / 1:1
- Social presets: TikTok, YouTube Shorts, Instagram Reels, YouTube, Instagram Post
- Advanced Studio: multi-layer timeline, keyframes, masking, chroma key, motion tracking, speed ramping, frame-by-frame, stabilization, AI hook/scene/speaker detection, B-roll, karaoke captions, motion graphics, 3D text, LUT, EQ, beat sync, custom export, auto save, undo/redo, gaming panel for Roblox / Fortnite

Live: https://fahim-rouge-eight.vercel.app/
